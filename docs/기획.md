# Busan LocalHub 구조 초안

## 화면 구성

- 메인: 부산 대표 이미지, 주요 메뉴, 챗봇 입력창
- 관광지: 관광지/문화시설/숙박/쇼핑/레포츠 카테고리, 검색, 카드 리스트, 상세 화면
- 축제/행사: 행사명, 기간, 장소, 문의처 테이블, 검색, 상세 화면
- 여행코스: 여행코스 카드 리스트 + 상세 화면
- 커뮤니티: FastAPI + SQLite 기반 게시글 목록, 상세, 글쓰기 등록, 비밀번호 기반 수정/삭제
- 챗봇: 프롬프트 입력, 사용자/봇 말풍선, 추후 `/api/chat` 연동

## 데이터

- 원본 위치: `busan/*.json`
- 사용 파일:
  - `부산_관광지.json`
  - `부산_축제공연행사.json`
  - `부산_여행코스.json`
- 주요 필드:
  - 공통: `title`, `addr1`, `tel`, `mapx`, `mapy`, `firstimage`
  - 행사: `eventstartdate`, `eventenddate`, `eventplace`
