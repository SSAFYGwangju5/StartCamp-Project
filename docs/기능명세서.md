# Busan LocalHub 기능명세서

## 프로젝트 개요

Busan LocalHub는 부산 방문 관광객이 지역 관광정보, 축제/행사, 여행코스, 커뮤니티, 챗봇을 한 화면에서 이용할 수 있도록 만든 지역정보 커뮤니티 MVP입니다.

## 기술 스택

| 구분 | 기술 |
|---|---|
| Frontend | Vue.js 3, Vite |
| Backend | FastAPI |
| Database | SQLite |
| AI | Gemini API |
| Data | 한국관광공사 TourAPI 4.0 부산 JSON |

## 주요 화면

### 1. 메인 / 공통 레이아웃

| 항목 | 내용 |
|---|---|
| 상단 배너 | 부산 여행 허브 소개 |
| 주요 탭 | 관광지, 축제/행사, 여행코스, 커뮤니티 |
| 우측 챗봇 | 부산 여행 질문 입력 및 답변 표시 |
| 출처 표기 | 한국관광공사 TourAPI 및 공공누리 제3유형 표기 |

### 2. 관광지

| 기능 | 내용 |
|---|---|
| 카테고리 필터 | 관광지, 문화시설, 숙박, 쇼핑, 레포츠 |
| 검색 | 장소명 또는 주소 기반 검색 |
| 목록 | 카드 형태로 장소 이미지, 이름, 주소 표시 |
| 상세 | 이미지, 주소, 전화번호, 좌표 표시 |
| 데이터 보정 | 병원/업체성 노이즈 항목 일부 제외 |
| 이미지 대체 | 원본 이미지가 없는 항목은 카테고리별 대표 이미지 표시 |

### 3. 축제/행사

| 기능 | 내용 |
|---|---|
| 검색 | 행사명 또는 장소 기반 검색 |
| 목록 | 행사명, 기간, 장소, 문의처 테이블 표시 |
| 상세 | 행사 이미지, 주소, 전화번호, 기간, 장소 표시 |

### 4. 여행코스

| 기능 | 내용 |
|---|---|
| 목록 | 여행코스 카드 표시 |
| 검색 | 코스명 또는 주소 기반 검색 |
| 상세 | 이미지, 주소, 전화번호, 좌표 표시 |

### 5. 커뮤니티

| 기능 | 내용 |
|---|---|
| 게시글 목록 | 제목, 작성자, 작성일, 조회수 표시 |
| 게시글 상세 | 제목, 작성자, 작성일, 조회수, 본문 표시 |
| 글쓰기 | 제목, 비밀번호, 내용 입력 |
| 수정 | 비밀번호 검증 후 제목/내용 수정 |
| 삭제 | 비밀번호 검증 후 삭제 |
| 저장 방식 | FastAPI API를 통해 SQLite에 저장 |

### 6. 챗봇

| 기능 | 내용 |
|---|---|
| 질문 입력 | 부산 여행 관련 질문 입력 |
| 답변 표시 | 사용자/봇 말풍선 형태로 표시 |
| 데이터 기반 답변 | 앱에 포함된 부산 관광/숙박/축제/여행코스 데이터 일부를 컨텍스트로 사용 |
| 검색 기반 답변 | 맛집, 날씨, 영업시간 등 최신 정보 질문은 Gemini Google Search grounding 활용 |
| 장애 대응 | Gemini 503 오류 시 1회 재시도 후 사용자용 안내 메시지 표시 |

## 필수 요구사항 대응

| 요구사항 | 대응 여부 | 구현 위치 |
|---|---|---|
| Vue.js 3 SPA | 완료 | `frontend/` |
| FastAPI 백엔드 | 완료 | `backend/app/main.py` |
| SQLite DB | 완료 | `backend/localhub.db` |
| 게시판 CRUD | 완료 | `/api/posts` |
| 비밀번호 기반 수정/삭제 | 완료 | `PUT`, `DELETE /api/posts/{post_id}` |
| 챗봇 API | 완료 | `POST /api/chat` |
| 부산 데이터 연동 | 완료 | `/api/tour/{category}` |
| 데이터 출처 표기 | 완료 | 프론트 footer, README |
| API Key 보안 | 완료 | `.env`, `.gitignore` |
| 배포 | 예정 | Netlify, Render |

## 제한 사항

- 음식점 전용 원본 JSON 파일은 현재 포함되어 있지 않음.
- SQLite는 로컬 MVP에는 적합하지만 운영 배포에서는 PostgreSQL 등 외부 DB 전환이 필요할 수 있음.
- 실시간 날씨/영업시간 등은 Gemini 검색 결과를 활용하며, 방문 전 재확인이 필요함.
